# 🏡 StayNest

StayNest is a full-stack Airbnb-inspired accommodation booking platform where users can discover unique stays, create listings, manage bookings, add reviews, and maintain wishlists. The application is built using Node.js, Express.js, MongoDB, and EJS with a responsive modern UI.

## 🚀 Live Demo

🔗 https://your-live-url.onrender.com

## ✨ Features

- 🔐 User Authentication & Authorization
- 🏡 Create, Edit & Delete Listings
- ☁️ Cloudinary Image Upload
- 🔍 Search Listings
- 🗂 Category-based Filtering
- ❤️ Wishlist Management
- ⭐ Reviews & Dynamic Ratings
- 📅 Booking System
- 🧳 My Trips
- ❌ Cancel Booking
- 🚫 Prevent Booking Own Listing
- 🗺 Interactive Maps using Leaflet
- 📱 Fully Responsive Design

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/spandey009/StayNest.git
```

Move into the project directory

```bash
cd StayNest
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
ATLASDB_URL=your_mongodb_url

SECRET=your_secret_key

CLOUD_NAME=your_cloudinary_name
CLOUD_API_KEY=your_cloudinary_key
CLOUD_API_SECRET=your_cloudinary_secret
```

Start the application

```bash
npm start
```

Open your browser and visit:

```
http://localhost:3000
```
